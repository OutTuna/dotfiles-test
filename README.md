# macOS dotfiles

Ветка `macos` содержит настройки macOS отдельно от Linux и Windows.

| Команда | Действие |
| --- | --- |
| `dc` | Показать кастомные команды с описаниями |
| `cfg` | Открыть `~/.config/fish/config.fish` в nvim |
| `acfg` | Открыть `~/.config/fish/conf.d/aliases.fish` в nvim |
| `sns` | Подключиться к серверу по локальной сети |
| `zsns` | Подключиться к серверу через ZeroTier |
| `c`, `cls` | Очистить терминал |
| `up` | Показать время работы Mac |

Алиасы редактируются в `.config/fish/conf.d/aliases.fish`. Fish автоматически загружает этот файл при запуске. Для применения изменений в текущем окне: `source ~/.config/fish/conf.d/aliases.fish`. Новую команду можно добавить в список `names` функции `dc`; отдельные пользовательские функции из `functions/*.fish` добавляются автоматически. Служебные функции с `_` и `fish_` не показываются.

Нужны fish и nvim. Подключения `sns` и `zsns` требуют личных записей `Host sns` и `Host zsns` в `~/.ssh/config`; ключи, пароли и приватные параметры SSH не входят в репозиторий. Перед копированием dotfiles сравните их со своими настройками.

## Текущие настройки Mac

Базовый снимок конфигурации от 13 октября 2026 года; Neovim обновлён 23 октября 2026 года:

- `.config/fish/` — fish, алиасы, функции и дополнения.
- `.config/kitty/` — kitty и тема терминала.
- `.config/starship.toml` — оформление приглашения fish.
- `.config/nvim/` — LazyVim с угольной палитрой на базе Gruvbox, деревом файлов слева, выбором Python venv в нижней строке и поддержкой C/C++, CMake, C#, Git, Markdown, Python и YAML. `lazy-lock.json` сохраняет версии плагинов.

Для восстановления скопируйте нужные файлы в соответствующие каталоги `~/.config/`, предварительно сохранив свои настройки. Плагины Neovim устанавливаются при первом запуске; для сохранённых версий используйте `:Lazy restore`. Требуются установленные fish, kitty, Neovim, Git, Starship, fastfetch и Homebrew; шрифт терминала — JetBrainsMono Nerd Font Mono.

Локальные данные fish (`fish_variables`), резервные копии, история, кэши, Git-метаданные Neovim и учётные данные не включены.

## Установка программ

После установки Homebrew выполните из корня репозитория:

```sh
brew bundle install --file=Brewfile
```

`Brewfile` содержит список программ этого Mac с Python 3.14 вместо Homebrew Python 3.13. Версии остальных пакетов не закреплены. Настройки fish выбирают Python 3.14 из Homebrew, а при его отсутствии — существующую установку Python.org. Установка пакетов не переносит виртуальные окружения и библиотеки pip; зависимости проектов устанавливайте в отдельных venv.


## Neovim на macOS

Интерфейс упрощён: отключены стартовый экран, Noice и плавная прокрутка; в нижней строке убраны часы и счётчик обновлений. Поиск, автодополнение, диагностика, Git, вкладки и подсказки сочетаний сохранены. Дерево файлов открывается при обычном запуске; служебные буферы, headless-запуски и уже восстановленные раскладки не перестраиваются.

| Сочетание в NORMAL | Действие |
| --- | --- |
| `Space e` | Показать или скрыть дерево файлов |
| `Space Space` | Найти файл |
| `Space /` | Найти текст в проекте |
| `Space c v` | Выбрать существующее Python-окружение из любого файла |
| Клик по `venv:` внизу | Открыть тот же выбор окружения |
| `K` / `gd` | Документация / переход к определению |

`Space c v` нажимается последовательно. Выбранный venv используется языковыми инструментами и новыми терминалами Neovim; уже открытый терминал нужно открыть заново. Само окружение в dotfiles не хранится и этой командой не создаётся.

### C/C++

Для CMake-проекта сгенерируйте базу параметров компиляции:

```sh
cmake -S . -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
```

clangd обнаруживает базу в стандартной папке `build`. Если проект использует другую папку, укажите её в локальном `.clangd`:

```yaml
CompileFlags:
  CompilationDatabase: build-debug
```

Папка должна содержать актуальный `compile_commands.json`, а зависимости проекта должны быть доступны. Настройки для конкретных проектов и абсолютные пути этого Mac в dotfiles не включены. CMake Tools также умеет создавать ссылку на базу после генерации. Редактирование Windows-проекта на Mac не заменяет его проверку Windows-компилятором; параметры локальной сборки описывают только активную платформу.

### C# / .NET

Для проверенной конфигурации установите SDK:

```sh
brew install dotnet@8
```

Команда `dotnet --info` должна работать в терминале, из которого запускается Neovim. Открывайте проект из папки с `.sln` или `.csproj`. OmniSharp устанавливается через Mason; при необходимости установите его вручную командой `:MasonInstall omnisharp` и перезапустите редактор. Только процессу OmniSharp задан `DOTNET_ROLL_FORWARD=Major`, чтобы он мог использовать установленную более новую версию runtime. Требуемые версии SDK/runtime самих проектов это не меняет.

Проверены подключение clangd к C++-проекту, семантические подсказки OmniSharp и сборка отдельного проекта `net8.0`. Для проектов с другой целевой версией .NET могут потребоваться дополнительные SDK/runtime; Windows-зависимые приложения по-прежнему проверяются в соответствующем окружении.
