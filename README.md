# macOS dotfiles

Ветка `macos` содержит настройки macOS отдельно от Linux и Windows.

| Команда | Действие |
| --- | --- |
| `dc` | Показать кастомные команды с описаниями |
| `cfg` | Открыть `~/.config/fish/config.fish` в nvim |
| `acfg` | Открыть `~/.config/fish/conf.d/aliases.fish` в nvim |
| `sns` | Подключиться к серверу по локальной сети |
| `zsns` | Подключиться к серверу через ZeroTier |
| `c`, `cls` | Очистить терминал |
| `up` | Показать время работы Mac |

Алиасы редактируются в `.config/fish/conf.d/aliases.fish`. Fish автоматически загружает этот файл при запуске. Для применения изменений в текущем окне: `source ~/.config/fish/conf.d/aliases.fish`. Новую команду можно добавить в список `names` функции `dc`; отдельные пользовательские функции из `functions/*.fish` добавляются автоматически. Служебные функции с `_` и `fish_` не показываются.

Нужны fish и nvim. Подключения `sns` и `zsns` требуют личных записей `Host sns` и `Host zsns` в `~/.ssh/config`; ключи, пароли и приватные параметры SSH не входят в репозиторий. Перед копированием dotfiles сравните их со своими настройками.

## Текущие настройки Mac

Снимок конфигурации от 13 октября 2026 года:

- `.config/fish/` — fish, алиасы, функции и дополнения.
- `.config/kitty/` — kitty и тема терминала.
- `.config/starship.toml` — оформление приглашения fish.
- `.config/nvim/` — Neovim на базе LazyVim, тема Gruvbox, дополнительные настройки clangd, Git, Python и YAML. `lazy-lock.json` сохраняет версии плагинов.

Для восстановления скопируйте нужные файлы в соответствующие каталоги `~/.config/`, предварительно сохранив свои настройки. Плагины Neovim устанавливаются при первом запуске; для сохранённых версий используйте `:Lazy restore`. Требуются установленные fish, kitty, Neovim, Git, Starship, fastfetch и Homebrew; шрифт терминала — JetBrainsMono Nerd Font Mono.

Локальные данные fish (`fish_variables`), резервные копии, история, кэши, Git-метаданные Neovim и учётные данные не включены.

## Установка программ

После установки Homebrew выполните из корня репозитория:

```sh
brew bundle install --file=Brewfile
```

`Brewfile` содержит список программ этого Mac с Python 3.14 вместо Homebrew Python 3.13. Версии остальных пакетов не закреплены. Настройки fish выбирают Python 3.14 из Homebrew, а при его отсутствии — существующую установку Python.org. Установка пакетов не переносит виртуальные окружения и библиотеки pip; зависимости проектов устанавливайте в отдельных venv.
