# macOS fish shortcuts

Ветка `macos` содержит настройки macOS отдельно от Linux и Windows.

| Команда | Действие |
| --- | --- |
| `dc` | Показать кастомные команды с описаниями |
| `cfg` | Открыть `~/.config/fish/config.fish` в nvim |
| `acfg` | Открыть `~/.config/fish/conf.d/aliases.fish` в nvim |
| `sns` | Подключиться командой `ssh sns` |
| `c`, `cls` | Очистить терминал |
| `up` | Показать время работы Mac |

Алиасы редактируются в `.config/fish/conf.d/aliases.fish`. Fish автоматически загружает этот файл при запуске. Для применения изменений в текущем окне: `source ~/.config/fish/conf.d/aliases.fish`. Новую команду можно добавить в список `names` функции `dc`; отдельные пользовательские функции из `functions/*.fish` добавляются автоматически. Служебные функции с `_` и `fish_` не показываются.

Нужны fish и nvim. Подключение `sns` требует личной записи `Host sns` в `~/.ssh/config`; ключи, пароли и приватные параметры SSH не входят в репозиторий. Перед копированием dotfiles сравните их со своими настройками.
